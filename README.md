# Haven

Модерационный Discord-бот на Python (disnake >= 2.11) с использованием Discord Components V2.

Полнофункциональный бот для модерации, управления и автоматизации Discord-сервера.
Все сообщения -- через Components V2, без embeds и без эмодзи.

## Запуск

```bash
pip install -r requirements.txt
HAVEN_TOKEN=<your-bot-token> python main.py
```

## Возможности

### Модерация
| Команда | Описание | Права |
|---------|----------|-------|
| `/mute` | Тайм-аут с интерактивным выбором длительности | moderate_members |
| `/unmute` | Снять тайм-аут | moderate_members |
| `/warn` | Предупреждение | moderate_members |
| `/warnings` | Список предупреждений | moderate_members |
| `/delwarn` | Удалить конкретный варн | moderate_members |
| `/clearwarns` | Очистить все варны | administrator |
| `/kick` | Кикнуть участника | kick_members |
| `/softban` | Бан + разбан (удаление сообщений) | ban_members |
| `/ban` | Бан (с поддержкой временного) | ban_members |
| `/unban` | Разбан по ID | ban_members |
| `/massban` | Бан нескольких по ID | administrator |
| `/purge` | Удаление сообщений с фильтрами | manage_messages |
| `/slowmode` | Медленный режим | manage_channels |
| `/lock` | Заблокировать канал | manage_channels |
| `/unlock` | Разблокировать канал | manage_channels |
| `/nuke` | Пересоздать канал | administrator |

| Команда | Описание |
|---------|----------|
| `/note add/list/delete/clear` | Заметки модераторов о пользователях |
| `/role add/remove/members` | Управление ролями |
| `/reactionrole create/addrole/send` | Реакционные роли |

| `/remind` | Напоминания |

### Тикет-система
- Панель с 6 категориями: Вопрос, Жалоба, Апелляция, Баг, Партнерство, Другое
- Приоритеты: Низкий, Средний, Высокий, Критический
- Claim тикета модератором
- Добавление участников
- Транскрипт (последние 500 сообщений)
- Архивирование и удаление

### Логирование событий
- Вход / выход участников
- Изменение ролей
- Удаление / редактирование сообщений
- Создание / удаление каналов и ролей
- Бан / разбан
- Голосовые каналы

|------|-----------|

| `warnings.json` | Предупреждения |
| `tickets.json` | Открытые тикеты |
| `tempbans.json` | Временные баны |
| `cases.json` | Кейсы модерации |
| `notes.json` | Заметки модераторов |
| `reminders.json` | Напоминания |
| `giveaways.json` | Розыгрыши |
| `reactionroles.json` | Реакционные роли |

## Технические детали

- Python 3.11+
- disnake >= 2.11
- Discord Components V2 (без embeds)
- Все в одном файле `main.py` (~3670 строк)
- 34 slash-команды
- Фоновые задачи: проверка временных банов (20с), напоминания (15с), розыгрыши (30с)
- Монохромная цветовая схема без эмодзи
- Интерфейс полностью на русском
